# JC Ricarte Website Icon Kit — Batch 05

Website Development icons: Custom Websites, Mobile Optimized, Clean Code, Fast Performance, Scalable Architecture.

**Design**: Light uses Deep Navy #0F2740 + Teal #2E7D73; dark uses White #FFFFFF + Teal #2E7D73.

**Files**: 10 true vector SVGs with transparent canvas (128×128 viewBox), plus 10 WebP (512×512, lossless transparency). SVGs are path-based and do not embed raster images.

**Use**: Prefer SVG in website markup; WebP for static raster implementation. Both support transparent backgrounds.

The image `Batch_05_Actual_Asset_Preview.png` is an assembled comparison for reviewing on light and dark surfaces.
