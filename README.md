# JC Ricarte Website

Brand asset library for the JC Ricarte website.

## Contents

- `assets/`: badge packs, light/dark web icons, and service mascots.
- Root ZIP archives: original packaged asset exports.
- Root PNG boards: approved brand and UI references.

This repository currently contains design assets, not a runnable website.
Some SVG files wrap raster artwork; preserve their referenced images.
Credential artwork does not independently verify certification or partnership status.
